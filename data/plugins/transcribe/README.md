# Расшифровка

Аудио и видео — в текст. Всё на этом компьютере, тем же «слухом», что понимает ваш голос.

**Что умеет**
- Запись созвона, лекции, интервью или голосовое → текст с метками времени [мм:сс] и субтитры `.srt`.
- Подходят mp3, wav, m4a, ogg, opus, flac, mp4, mov, mkv, webm и другие форматы. Длинные записи — тоже: Лира режет их по паузам.
- Все расшифровки — в одном списке с поиском по тексту: нажали на найденное место — видно, что говорили вокруг.
- Текст и субтитры сохраняются в «Мои файлы» → «Расшифровки»: их можно открыть, переслать, а Лира найдёт их обычным поиском.
- Спросите Лиру по записи: «сделай выжимку», «о чём договорились», «где говорили про сроки».

**Как пользоваться**
Студия → «Плагины» → «Расшифровка» → вкладка «Расшифровки» → «Выбрать файл» (или перетащите файл на страницу).
Голосом: «Расшифруй запись созвона» — Лира скажет, когда закончит.

**Приватность**
Звук никуда не отправляется, если «Слух» работает на этом компьютере (GigaAM или Vosk). Если в «Слухе» выбран сервер —
расшифровывает он.
