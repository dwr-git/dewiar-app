# Тендеры

Лира ищет новые тендеры по вашей теме на площадках госзакупок Беларуси и присылает только подходящие.

**Что умеет**
- Просматривает goszakupki.by и icetrade.by (и свою площадку, если указать адрес поиска с `{QUERY}`).
- Разбирает выдачу без нейросети: сама находит строки с тендерами, номер, заказчика, срок и цену.
- Оценивает каждый тендер от 0 до 10: совпадение с запросом, плюс-слова; минус-слова отбрасывают.
- Помнит, что уже находила: один тендер из разных запросов — одна запись; просмотренные не повторяются.
- По будням в 9:00 присылает новые (включите дело в карточке).
- Разбирает любой тендер по ссылке: что нужно, сроки, обеспечение, требования.

**Как настроить**
«Что искать» — запросы через точку с запятой: `видеонаблюдение; системы безопасности`. Плюс-слова поднимают тендер
выше, минус-слова убирают совсем. «Присылать от балла» — порог для ежедневной сводки.

Найденное хранится только на этом компьютере.
