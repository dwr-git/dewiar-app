# «Радар» — Лира-аналитик вашей ниши

Владелец 12.11.2026 (по образцу своего серверного evolution): человек даёт источники по своей теме (сайты, ленты,
YouTube, Telegram-каналы…), Лира сама читает их по расписанию, разбирает каждый материал, видит тренды и важное,
утром приносит бриф, срочное — сразу, а в любой момент отвечает «что сейчас происходит в нише и куда идёт».
Раздел «Работа → Радар». Русский и английский с первого дня (ключи `insight.*` в `data/i18n`). Вид — чтобы «дух
захватывало»: «Поле сигналов», тренды со спарклайнами, «Галактика» тем — в стиле студии, светлая и тёмная тема.

Внутреннее имя — `insight` (имя `radar` занято: «Близкие» → «Рядом», ui/studio/radar.js).

## Устройство

- `core/insight.py` — всё без движка (проверяется отдельно):
  - **Источники**: `detect(link)` → `{kind, url, feed, name}`: RSS/Atom, сайт (ищем ленту в `<link rel=alternate>`,
    нет — читаем страницу как список ссылок), YouTube (`/feeds/videos.xml?channel_id=`), Telegram `@канал`
    (`t.me/s/канал`), Reddit (`/r/x/.rss`), GitHub (`/releases.atom`), VK, Дзен (страница), одна статья.
  - **Обход** `crawl(store, fetch)`: новые материалы (заголовок, ссылка, дата, текст начала) — в очередь разбора; повторы
    отсекаются по нормализованной ссылке и заголовку.
  - **Разбор** `analyze_prompt(mission, item)` / `parse_analysis(raw)`: суть (1–2 фразы), «почему важно для вас» (по
    миссии), тип (релиз, аналитика, новость, практика, инцидент, мнение, видео), 2–4 тега, сущности (компании, продукты,
    люди), сигнал 0–10 (не «интересно ли», а насколько это меняет картину для этой ниши). Модель — как у Лиры (облако
    Dewiar или своя); лимит разборов в сутки (`insight.daily_max`), ночью — полный, днём — бережно.
  - **Тренды** `trends(items, now)`: по тегам и сущностям — сутки против нормы за предыдущие 7 дней; импульс, «новая
    тема» / «растёт» / «стабильно» / «спадает», спарклайн 8 дней, сколько источников.
  - **Бриф** `brief_prompt(...)` → заголовок дня, до 5 пунктов, «главное» (3 материала с разбором) — раз в сутки утром
    и по кнопке.
  - **Срочное**: сигнал ≥ `urgent_min` (8,5) или тема с импульсом ≥ 3 и ≥ 3 материала за сутки — весточка сразу
    (виджет, телефон, Telegram), не чаще раза в час, тише ночью.
  - **Разум**: миссия (ниша словами — задаёт человек), картина мира (тезисы со ссылками на материалы), гипотезы
    (проверяемые прогнозы со сроком) — ночью «эволюция»: модель обновляет тезисы, ставит и проверяет гипотезы по новым
    материалам; точность прогнозов — подтвердились / нет.
  - **Галактика**: созвездия — группы по тегам (совместная встречаемость), точки — материалы.
  - Хранилище — `STATE_DIR/insight/`: `sources.json`, `items.json` (до 3000 последних), `brief.json`, `mind.json`,
    `log.json` (такты обхода).
- Движок: команды `insight_*` (студия), фоновый поток (такт: днём раз в 20 мин, ночью — раз в 5), инструмент модели
  `insight_ask` (что важного, почему растёт тема, поиск по разобранному — «Спросите аналитика» и голосом).
- Студия: раздел «Радар» — вкладки «Пульс», «Лента», «Тренды», «Источники», «Разум», «Галактика»; на «Главной» —
  карточка с заголовком брифа и самым сильным сигналом.

## Экономика

Разбор материала — короткий запрос (начало текста до ~1,5 тыс. знаков). Облако Dewiar — талеры (видно в «Пульсе»:
потрачено за сутки), своя модель — бесплатно. Лимит в сутки по умолчанию — 60 материалов.
