# Презентация

Результат — ОДИН самодостаточный файл `outputs/slides.html`: открывается в браузере, листается стрелками ← →
и пробелом, «F» — на весь экран, «Печать → Сохранить как PDF» даёт PDF по слайду на страницу.

## Порядок (8–12 шагов)
1. Пойми тему, аудиторию и длину (по умолчанию 8–10 слайдов). Нужны факты — web_search / read_webpage, документы
   пользователя — search_documents. Цифры не выдумывай.
2. update_plan: план по слайдам (заголовок каждого — одна мысль).
3. read_skill_file("slides", "deck.html") — возьми шаблон ЦЕЛИКОМ: стили и скрипт уже готовы, меняй только
   секции `<section class="slide">` и `<title>`. Свой CSS почти не нужен.
4. write_file outputs/slides.html — весь файл (если длинный — частями, append=true).
5. read_file — проверь: все секции закрыты, есть `</html>`, на слайде не больше 5 пунктов и ~40 слов.
6. show outputs/slides.html (title — название презентации), затем finish: что внутри и как сделать PDF.

## Виды слайдов (классы шаблона)
- `slide title` — титульный: `.kicker` (надзаголовок), `h1`, `p.lead`, `.meta` (автор · дата).
- `slide` — обычный: `h2` + список `ul` или абзацы `p`.
- `slide split` — две колонки: `<div class="cols"><div>…</div><div>…</div></div>`.
- `slide big` — одна большая цифра или мысль: `.num` + `p`.
- `slide quote` — цитата: `blockquote` + `.who`.
- `slide cards` — 3–4 карточки: `<div class="grid"><div class="card"><b>Заголовок</b><p>…</p></div>…</div>`.
- `slide end` — финальный: спасибо / контакты / призыв.
Картинки: `<img src="https://…">` (только надёжные адреса) или эмодзи в `.ico`. Таблица — обычная `<table>`.

## Правила хорошего слайда
- Одна мысль на слайд, заголовок — вывод («Продажи выросли на 30%»), а не тема («Продажи»).
- Не больше 5 пунктов по 6–8 слов. Цифры крупно. Источник мелко внизу: `<div class="src">Источник: …</div>`.
- Тема оформления: `<body class="theme-dark">` (по умолчанию) или `theme-light` — если просят светлую.
