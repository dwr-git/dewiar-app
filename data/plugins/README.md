# Как сделать свой плагин

Плагин — это папка, которую Dewiar ставит одной кнопкой. В ней всё, что нужно для одного умения: инструкция для помощницы
(навык), подключения к внешним программам и сервисам (MCP), настройки, которые человек заполнит при установке, примеры фраз
и дела по расписанию.

## Из чего состоит

```
my-plugin/
  plugin.json            описание плагина
  skills/
    my-skill/SKILL.md    инструкция для помощницы (формат Agent Skills, как у Claude)
  README.md              для людей: что умеет, как пользоваться
```

## plugin.json

```json
{
  "id": "garden-diary",
  "name": "Дневник сада",
  "icon": "🌷",
  "color": "#9BE15D",
  "category": "Дом",
  "tagline": "Что и когда цвело, чем подкармливали",
  "description": "Говорите, что сделали в саду, — помощница ведёт дневник и напоминает о подкормках.",
  "version": "1.0",
  "author": "Ваше имя",
  "skills": ["garden-diary"],
  "phrases": ["Запиши: подкормил розы", "Когда я последний раз подкармливал розы?"],
  "uses": ["save_note", "find_notes", "set_reminder"],
  "settings": [
    { "key": "city", "label": "Где сад", "type": "text", "placeholder": "Минск" },
    { "key": "style", "label": "Как отвечать", "type": "select", "options": ["коротко", "подробно"], "default": "коротко" }
  ],
  "jobs": [
    { "id": "weekly", "title": "Сводка по субботам в 10:00", "when": "каждую субботу в 10",
      "task": "Сделай короткую сводку дневника сада за неделю для {city}" }
  ],
  "mcp": {
    "files": { "type": "stdio", "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "~/Сад"] }
  }
}
```

| Поле | Что это |
|---|---|
| `id` | латиница, цифры и дефис; уникальное имя |
| `name`, `icon`, `color`, `category` | как плагин выглядит в каталоге |
| `tagline` | одна строка под названием |
| `description` | что умеет — несколько предложений для человека |
| `skills` | папки в `skills/`, которые включаются вместе с плагином |
| `phrases` | что можно сказать — показываются в карточке, нажатие копирует фразу |
| `uses` | какие инструменты помощницы задействованы — для подписи «Что внутри» |
| `settings` | поля, которые человек заполняет: `text`, `select` (с `options`), `number`, `toggle` |
| `jobs` | дела по расписанию; человек включает каждое сам. `{key}` в `task` — значение настройки |
| `mcp` | MCP-серверы плагина: `stdio` (программа: `command`, `args`, `env`) или `http` (`url`, `headers`) |
| `try` | фраза для витрины «Попробуйте плагин» на главной; нет — первая из `phrases` |
| `video` | ролик о плагине: id урока Академии (`15-plugins`) или адрес `https://…` |

У настройки можно указать `"required": true` — без неё плагин не включится с главной одной кнопкой: откроется его
панель, чтобы заполнить.

## Навык

`skills/<имя>/SKILL.md` — обычный навык Dewiar:

```
---
name: garden-diary
description: Дневник сада: «запиши, что сделал в саду», «когда подкармливал…». Пишите, какими словами о нём просят.
---
# Дневник сада
1. «Запиши: …» — save_note «Сад — дневник», append=true, строка с датой.
…
```

Помощница видит только `description` и по нему решает, когда открыть навык. Настройки плагина сами добавляются к тексту
навыка: «Настройки плагина «Дневник сада»: Где сад — Минск; Как отвечать — коротко».

## Свой код в плагине

Готовый модуль на Python (разбор резюме, поиск тендеров, свой сервис) кладётся прямо в папку плагина и запускается как
MCP-сервер — его функции становятся действиями помощницы:

```json
"mcp": {
  "tenders": { "type": "stdio", "command": "{python}", "args": ["{plugin_dir}/server.py"] }
}
```

- `{plugin_dir}` — папка плагина на компьютере, `{python}` — Python самой программы (отдельно ставить не нужно, и в
  Windows тоже).
- Библиотеки модуля — в папку `lib/` плагина (`pip install --target lib …`): она первой попадает в путь поиска модулей.
- `server.py` говорит по протоколу MCP (stdio): `initialize`, `tools/list`, `tools/call`. Пример самого маленького
  сервера — `tests/mcp_test_server.py` в исходниках.
- Что программа передаёт серверу: `DEWIAR_PLUGIN_DATA` — его папка для данных (переживает переустановку),
  `DEWIAR_PLUGIN_SETTINGS` — настройки из карточки (JSON; значения по умолчанию возьмите из своего plugin.json),
  `DEWIAR_WORKSPACE` — папка Dewiar (для файлов, которые человек будет открывать сам). Ядро Dewiar — в пути модулей:
  `import knowledge; knowledge.extract(path)` достаёт текст из PDF, Word и ODT.
- Действие, которое только читает или пишет в свою папку данных, отметьте `"annotations": {"readOnlyHint": true}` —
  помощница не будет спрашивать «Выполнить?» каждый раз.
- Примеры: встроенные «Тендеры», «Рекрутер» и «Художник» (`data/plugins/…/server.py`).

## Как установить

Студия → «Плагины» → «Установить из файла» → zip-архив с папкой плагина. Установленный плагин можно настроить, включить
его дела по расписанию или удалить — вместе с его навыками и MCP-серверами.

## Безопасность

- Навык — это текст: он ничего не запускает сам.
- Программы плагин запускает только через MCP-серверы. Они видны в списке «MCP-серверы», их можно выключить, и каждое
  действие, которое что-то меняет, помощница сначала спрашивает (если вы не отметили «доверять»).
- Ставьте плагины только от тех, кому доверяете.
