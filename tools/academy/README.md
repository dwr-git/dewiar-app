# ИИ Академия Лиры — мультфильмы-уроки

Короткие ролики (45–90 с) — по одной возможности Лиры на урок: для YouTube и для уроков внутри программы.

Урок — папка `lessons/<номер-имя>/`:

- `lesson.json` — реплики по сценам: `who` (lira, patrik), `sub` — титр на экране, `tts` — как произносить
  («И И», «Чат Джи Пи Ти», «девиар точка про»); паузы: `lead` (пауза перед первой репликой сцены), `gap_in`, `gap_scene`, `tail`.
- `film.html` — сцена 1920×1080. Таймлайн приходит в `window.TL`; `render(T, кадр)` рисует момент T. Облики — настоящие
  (`ui/assets/entities.js`, живые лица), рот двигается по громкости реплики (`TL.env`).

Сборка:

```
python3 tools/academy/build.py lessons/01-council           # голос, звук, видео → lessons/01-council/out/lesson.mp4
python3 tools/academy/build.py lessons/01-council 4 27 53   # кадры в эти секунды — проверить вёрстку
```

Нужны piper, ffmpeg, numpy и Playwright с Chromium. Голоса — те же, что у персонажей в программе (Лира — irina,
Патрик — denis), берутся из выпусков sherpa-onnx на GitHub в `~/.cache/dewiar-academy`. Кадры снимаются по одному при
подменённом времени страницы — ровно 30 в секунду. Музыка — тихий пэд, приглушается под голос; громкость −16 LUFS.

Произношение проверяется распознаванием (Vosk из `data/`): если слово распознаётся криво — правьте `tts`, не `sub`.

Второй сезон (08–12) собран генератором `series/`: общая часть серии (фон, облики, титры, рот по громкости —
`lipsync`) — в файлах css_*/js_*, своя сцена урока — в `series/sNN.py` (CSS, разметка, render по репликам):

```
python3 tools/academy/series/mk.py tools/academy/series/s08.py tools/academy/lessons/08-prompter   # → film.html
```

Голоса одним архивом на несколько уроков (страница «Академия» в кабинете) делятся по числу реплик каждого урока.

Уроки: 01 — «Совет ИИ», 02 — «Дозор», 03 — «Заявки с сайта». Порядок дальше (владелец 29.10): сначала бизнес — 04
«Поручения сотрудникам» (поставить задачу и проконтролировать выполнение), 05 «Работа с клиентами» (карточки, следующий
шаг, сделки, кто должен), 06 «Рассылка», 07 «Посты в Telegram»; потом общее и полезное для всех («Документы», «Утро с
Лирой», «Заметки», «Одна Лира на всех устройствах»…); детский режим и «Для старших» — одним роликом ближе к концу, когда
полезное уже показано (сцена «Для старших» — lessons/later-senior). Сезон 2 (владелец 29.10: «прикладное для бизнеса и эффективности в жизни»):
08 «Суфлёр на переговорах», 09 «Ваши документы», 10 «Почта голосом», 11 «Дела по расписанию», 12 «Утро с Лирой»; дальше —
«Деньги голосом», «Задачи» (большую работу Лира делает сама).
