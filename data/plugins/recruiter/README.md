# Рекрутер

Помощник по подбору персонала: разбирает резюме, отбирает под вакансию, оценивает и ведёт кандидатов по этапам.

**Что умеет**
- Резюме из файла или целой папки: PDF, Word (.docx), OpenOffice (.odt), RTF и текст. Повторы не заводятся.
- Сразу, без нейросети: ФИО, телефон, почта, Telegram, город, возраст, стаж, желаемая должность и зарплата
  (форматы rabota.by и hh и свободные резюме).
- Что уточнить на собеседовании: стаж больше возможного по возрасту, senior при малом стаже, частая смена работы,
  нет контактов.
- Вакансии и отбор под них: у кого больше совпадений по требованиям, чего не хватает.
- Оценка лучших по пяти критериям — навыки, опыт, формат и условия, образование, языки — с итогом по весам
  (40 / 30 / 13 / 10 / 7): одинаково для всех кандидатов и воспроизводимо.
- Сравнение двоих, вопросы к собеседованию, письма кандидатам, воронка: новый → интересен → собеседование → оффер →
  принят / отказ.
- По будням в 10:00 может разбирать новые резюме из папки (включите дело в карточке).

**Как настроить**
Укажите «Папку с резюме» — туда удобно сохранять файлы с почты и сайтов вакансий.

Все данные кандидатов хранятся только на этом компьютере. Оценка — подсказка для человека, решение — за вами.
