Первый сервер для Лиры

Пошаговая инструкция: от голого компьютера с двумя видеокартами до сервера, который отвечает людям вместо главного, когда тот занят, и рисует картинки «как фото» для «Художника». Каждый шаг — что сделать и как понять, что получилось.

Dewiar 0.77.0 и новее · 31 октября 2026 · сервер с двумя видеокартами NVIDIA (RTX 3090 или RTX A4000)

Сайт сам решает, кто отвечает: пока у главного сервера есть свободные места — он; заняты — следующий разговор сразу уходит новому серверу. Картинки «как фото» рисует только новый сервер (если вы их включите). Настраивать сайт руками не нужно — новый сервер сам сообщит о себе.

1Что нужно заранее

  • Сайт обновлён до 0.77.0. Кабинет → «Обновления» → архив dewiar-server-0.77.0.zip → «Опубликовать».
  • Сервер: две видеокарты NVIDIA, оперативной памяти от 64 ГБ (минимум 32 ГБ без картинок), SSD от 250 ГБ.
  • Флешка на 8 ГБ — для установки Ubuntu.
  • Сеть: сервер подключён кабелем к той же сети, что и сервер сайта, и у него есть интернет.
  • Монитор и клавиатура — только на время установки Ubuntu. Дальше всё можно делать с другого компьютера.

2Что поставить на ваши карты

КартыЧто выбрать в кабинетеЧто получится

3Поставить Ubuntu Server 24.04

  1. На любом компьютере скачайте Ubuntu Server 24.04 LTS: ubuntu.com/download/server (файл .iso, ~3 ГБ).
  2. Запишите его на флешку программой balenaEtcher или Rufus: выбрать файл → выбрать флешку → «Flash» / «Старт».
  3. Вставьте флешку в сервер, включите его и выберите загрузку с флешки (клавиша F11, F12 или Del при включении — на экране пишут какая).
  4. Установщик спросит по очереди. Отвечайте так:
    • язык — English (так меньше путаницы с раскладкой);
    • тип установки — Ubuntu Server (не «minimized»);
    • сеть — оставить как есть (адрес получится сам); запишите адрес, который он покажет, например 192.168.1.50;
    • диск — «Use an entire disk» (весь диск, всё на нём сотрётся);
    • имя и пароль — например имя dewiar, пароль надёжный, запишите его;
    • отметьте «Install OpenSSH server» — чтобы потом заходить с другого компьютера;
    • дополнительные программы (snaps) — ничего не отмечать.
  5. Дождитесь «Installation complete», выньте флешку, нажмите «Reboot Now».
  6. После перезагрузки войдите с вашим именем и паролем. Обновите систему: 
    sudo apt update && sudo apt -y upgrade && sudo reboot
  7. В настройках роутера закрепите за сервером его адрес (DHCP-резервирование), чтобы он не менялся.
Получилось, еслис другого компьютера заходит команда ssh dewiar@192.168.1.50 (ваш адрес и имя). С этого момента монитор и клавиатура серверу не нужны.

4Взять команду в кабинете

  1. Кабинет dewiar.pro → вкладка «Мощности» → блок «Новый сервер — одной командой».
  2. В списке выберите план по таблице из шага 2. Поле рядом оставьте пустым — модель скачается сама.
  3. Для 3090 с картинками отметьте «и картинки на последней карте».
  4. «Получить команду» → «Скопировать команду». Код в команде живёт 6 часов.
curl -fsSL "https://dewiar.pro/dwrapp/cloud.php?p=/worker.sh" | sudo bash -s -- K7M-42Q https://dewiar.pro/dwrapp/cloud.php

Так выглядит команда — код и адрес у вас будут свои.

5Запустить на сервере

  1. Зайдите на сервер: ssh dewiar@192.168.1.50. Посмотрите карты: nvidia-smi (если пишет «not found» — нормально, драйвер поставит скрипт).
  2. Вставьте команду из кабинета (правая кнопка мыши в окне терминала), Enter, пароль сервера.
  3. Если скрипт написал «Перезагрузите сервер и выполните ту же команду ещё раз» — это он поставил драйвер видеокарт: 
    sudo reboot
    подождите минуту, зайдите снова и вставьте ту же команду.
  4. Дальше просто ждать. Скрипт пишет, что делает: Docker → образ vLLM (~10 ГБ) → модель (~16 ГБ) → «порт 8001: отвечает» → «готово — сервер в кабинете». С картинками ещё ~30 ГБ: «картинки: модель загружается…» → «картинки: готово». Первый раз — от 30 минут до 2 часов, смотря какой интернет. Окно можно не трогать.
  5. В самом конце скрипт сам запускает проверку (шаг 6).

6Проверить — всё ли работает

На сервере — одной командой

sudo dewiar-worker check

Покажет по строке на каждую проверку: ✅ — в порядке, ❌ — что не так и что сделать. Проверяет драйвер и карты, Docker, видны ли карты внутри Docker, файл настроек, отвечает ли модель на каждой карте и за сколько, рисует ли пробную картинку 512×512 и за сколько, открывается ли сайт с этого сервера. В конце — «Всё в порядке» или «Проблем: N».

В кабинете

  1. «Мощности» → «Обновить». В списке «Дополнительные серверы» появились строки: «имя · карта 0» и, если включали картинки, «имя · картинки».
  2. У каждой зелёная точка. У мозга — «действия ✓», модель qwen3.8-27b-awq-vd. У картинок — flux.1-schnell.
  3. Нажмите «Проверить» у каждой: сайт задаст вопрос модели (или нарисует пробную картинку) и покажет время.
  4. Вкладка «Сервер» → «Проверка»: строка «Мощности: N из N отвечают».

В самой Лире

  1. Студия → «Плагины» → «Художник» → «Установить» (или на главной — карточка «Попробуйте плагин»).
  2. Скажите: «Нарисуй фотографию рыжего кота на подоконнике, утренний свет». Откроется браузер с картинкой — генератор работает.
  3. Мозг нового сервера включается сам, когда главный занят. Видно в кабинете → «Мощности» вверху: «ответили дополнительные: N из M» за час.

7Если что-то не так

Что видноЧто сделать
«Код не подходит или устарел»Прошло больше 6 часов. Кабинет → «Мощности» → «Получить команду» — новая команда.
«Видеокарт не вижу (nvidia-smi)»sudo ubuntu-drivers install, затем sudo reboot и та же команда из кабинета.
Долго «модель загружается…»Первый раз это нормально. Что происходит: sudo dewiar-worker logs 0 (картинки — logs image). Выйти — Ctrl+C.
«CUDA out of memory» в журналеНе хватает памяти карты. sudo nano /etc/dewiar-worker.conf: CONTEXT=16384 или SEATS=2; затем sudo dewiar-worker apply.
Картинки: «Killed» или долго и ошибкаМало оперативной памяти для FLUX. В файле настроек: IMAGE_MODEL=stabilityai/stable-diffusion-xl-base-1.0 (легче), затем sudo dewiar-worker apply.
В кабинете красная точка «не отвечает»Сайт не видит сервер. На сервере сайта: curl http://192.168.1.50:8001/v1/models. Нет ответа — сеть или брандмауэр (шаг 10).
«неверный ключ доступа»На новом сервере: sudo grep KEY /etc/dewiar-worker.conf — этот ключ вставить в кабинете у строки сервера.
«без действий»В файле настроек TOOLS=qwen3_coder, затем sudo dewiar-worker apply.
В Лире: «генератор картинок пока не подключён»В кабинете нет строки «· картинки» или она красная — sudo dewiar-worker check на сервере.

8Управление сервером

sudo dewiar-worker checkполная проверка с ✅ и ❌
sudo dewiar-worker statusкоротко: отвечает ли каждая карта
sudo dewiar-worker logs 0журнал карты 0 (logs image — картинок). Выйти — Ctrl+C
sudo dewiar-worker applyприменить изменения из файла настроек и сообщить сайту
sudo dewiar-worker stopостановить всё

После перезагрузки сервера всё запускается само. Ничего делать не нужно.

9Поменять план без переустановки

Все настройки — в файле /etc/dewiar-worker.conf. Открыть: sudo nano /etc/dewiar-worker.conf (сохранить — Ctrl+O, Enter; выйти — Ctrl+X). После изменений — sudo dewiar-worker apply.

IMAGES=on / offкартинки включены или нет
IMAGE_GPU=1на какой карте картинки (пусто — на последней); на ней мозга не будет
IMAGE_MODEL=…FLUX.1-schnell (лучше, от 64 ГБ памяти компьютера) или stable-diffusion-xl-base-1.0 (легче)
COPIES=per-gpu / oneпо копии мозга на карту или одна на все (для карт по 16 ГБ — one)
SEATS=4разговоров сразу на одну копию. Поменяли — такое же число в кабинете в поле «Мест»

10Безопасность

  • Порты 8001, 8002 и 8100 не открывайте в интернет — сервер нужен только сайту, внутри вашей сети.
  • Если включаете брандмауэр — разрешите вход только от сервера сайта: 
    sudo ufw allow from 192.168.1.10 to any port 8001:8100 proto tcp
sudo ufw allow OpenSSH && sudo ufw enable
    (вместо 192.168.1.10 — адрес сервера сайта).
  • Ключ доступа — в файле, который читает только администратор. Никому его не пересылайте.
  • Картинки: не больше 30 на человека в день (кабинет → настройка image_daily).

11Нагрузка сайта — само

С 0.77 сайт сам подбирает, сколько мест держать для «Близких» и долгих запросов, по числу обработчиков PHP. Во вкладке «Сервер» видно «подобрано само из N обработчиков PHP». Ничего менять не нужно. Если «занято» за час появляется часто — значит, людей стало много: прибавьте обработчиков PHP (pm.max_children), места подстроятся сами.
