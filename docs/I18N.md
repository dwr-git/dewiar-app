# Языки Dewiar

С 0.88 программа говорит на языке человека. Владелец 11.11: «тексты — в отдельных файлах `ru.json`, `en.json`; нет
русского в системе — сразу английский; в настройках — переключение; любой язык — иврит, немецкий, французский,
китайский — добавлять легко».

## Как устроено

- **Словари** — `data/i18n/<код>.json`: `{"ключ": "текст"}`; для чисел — `{"one": …, "few": …, "many": …, "other": …}`
  (формы — по правилам CLDR языка), подстановки — `{n}`, `{name}`. Русский (`ru.json`) — исходный.
- **Окна** (студия, виджет; телефон — следующим этапом) берут словари из `ui/assets/i18n.data.js` —
  собирает `python3 tools/i18n_build.py` (он же печатает, сколько переведено в каждом языке).
  В разметке — `data-i18n="ключ"`, `data-i18n-title`, `-placeholder`, `-aria-label`; русский текст остаётся в разметке
  (без вспышки при загрузке) и обязан совпадать с `ru.json` (`tests/i18n_test.py`). В коде — `t("ключ", {n, name})`,
  даты и числа — `toLocaleString(dwLocale(), …)`.
- **Ядро** — `core/i18n.py`: `t(key, lang, **params)`, `resolve(ui.lang)`, `system_lang()`, `plural_form()`.
- **Какой язык**: `ui.lang` = `auto` | код. `auto` — по системе: русский, если система на русском, украинском,
  белорусском, казахском (или на Windows стоит такая раскладка); есть словарь языка системы — он; иначе английский.
  У тех, кто пользовался Dewiar до 0.88, — `ru` (не меняем язык при обновлении). Окна получают язык в адресе (`?lang=`),
  студия переключает его без перезапуска (`dwSetLang`).
- **Нет строки** в выбранном языке — английская, затем русская, затем сам ключ.
- **Справа налево** (иврит, арабский, фарси, урду) — `dir="rtl"` у страницы; новая вёрстка — логическими свойствами
  (`margin-inline-start`, `padding-inline`, `inset-inline-end`), а не left/right.
- **Храповик** — `tools/i18n_ratchet.py`: сколько русского текста осталось в интерфейсах мимо словарей, по файлам.
  Новый текст — только ключом; переведя часть, опустите пределы: `python3 tools/i18n_ratchet.py --update`.
  Комментарии и журнал для программистов — по-русски.

## Как добавить язык (например, немецкий)

1. Скопировать `data/i18n/en.json` в `data/i18n/de.json`, поставить `"lang.name": "Deutsch"` (имя языка на нём самом) и
   перевести строки. Непереведённые можно оставить — покажутся английскими.
2. `python3 tools/i18n_build.py` — язык сам появится в «Оформлении» → «Язык программы», выберется у людей с немецкой
   системой. Код не правится.
3. Формы чисел: окна берут их из браузера (`Intl.PluralRules`, любые языки); в ядре — `core/i18n.py: plural_form`
   (русский, украинский, польский, иврит, арабский, французский, китайский, японский и «как в английском» уже есть).
4. Перевод проверяет носитель языка: модель делает черновик, человек — выпуск.
5. Голос и слух на этом языке: голос Piper своего языка (`core/tts.py`), распознавание — многоязычная модель; ответы
   модели — на языке программы (`core/engine_answer.py`, справка к вопросу).

## Что уже переведено

0.88: меню студии, «Главная» (приветствие, дата), «Оформление» → «Язык программы», оформления «Чата для сайта».
Дальше по плану («Dewiar для мира»): первые шаги, виджет, «Чат», «Мозг», «Слух», «Голос», затем все разделы и телефон.
0.89: виджет — главные строки состояния («Слушаю», «Думаю», микрофон, сон, запуск, обновление, баланс; ключи `hud.*`);
телефон берёт те же словари (`android/tools/www_assemble.sh` кладёт `i18n.data.js`, `i18n.js`; index.html подключает
их первыми). Новые файлы телефона — только ключами: «Клиенты» (`cli.*`, `clients.js`, через `cT`), планшет и «Dewiar
на компьютере» (`tab.*`, `pci.*`, `tablet.js`, через `tbT`), плитки «Всё» (`apps.*`). Описания инструментов модели —
по-английски (модели понимают их на любом языке разговора), ответы инструментов — из словарей. Выбор языка в самом
приложении телефона — следующий шаг (пока русский; `dwSetLang` уже работает).
