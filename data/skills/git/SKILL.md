# Навык: работа с git-репозиторием

> Когда задача — про репозиторий: клонировать, посмотреть историю/диффы, внести и закоммитить изменения, собрать патч. git на компьютере установлен.

## Базовое
```bash
git clone <url> repo && cd repo     # клонировать (нужен доступ в сеть)
git status                          # что изменено
git log --oneline -20               # последние коммиты
git diff                            # незакоммиченные правки
git diff <файл>                     # правки конкретного файла
```

## Внести изменения
```bash
git checkout -b feature/имя         # ветка под задачу
# ... правки файлов ...
git add -A && git commit -m "Понятное сообщение: что и зачем"
git diff main..HEAD                 # что отличается от базовой ветки
git format-patch main --stdout > outputs/changes.patch   # патч для передачи
```

## Правила
- Перед коммитом ПРОВЕРЬ правки (`git diff`) и, если это код, прогони тесты
  (скилл testing) — не коммить сломанное.
- Коммить логически связанные изменения вместе, сообщение — по сути.
- Не выполняй `push`/деструктивные операции (`reset --hard`, `clean -fd`, `push --force`)
  без явной просьбы пользователя.
- Секреты/токены не коммить; проверь, что их нет в диффе.
